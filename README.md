# 🚗 Rental Vehicle in Uttarakhand

A complete **Vehicle Rental Management Website** built using **PHP, MySQL, HTML, CSS, JavaScript, Bootstrap, phpMyAdmin, and WAMP Server**. This project allows tourists and local travelers to rent **Cars, Bikes, and Scooties** across popular destinations in Uttarakhand on a daily rental basis.

The platform provides a simple and user-friendly interface where users can browse available vehicles, check rental prices, submit booking requests, and explore travel destinations across Uttarakhand.

---

## 🌟 Features

* 🚗 Car Rental System
* 🏍️ Bike Rental System
* 🛵 Scooty Rental System
* 📅 Daily Rental Pricing
* 📝 Online Booking Form
* 🔐 Customer KYC Information Collection
* 📍 Uttarakhand Tourist Destination Showcase
* 📞 Contact & Inquiry Form
* 📱 Fully Responsive Design
* 🗄️ MySQL Database Integration

## 🚀 Project Overview

Rental Vehicle in Uttarakhand is designed to simplify transportation for tourists visiting various destinations such as:

* Mussoorie
* Rishikesh
* Haridwar
* Nainital
* Kedarnath
* Dehradun
* Other major locations in Uttarakhand

## ⚙️ Installation Guide

### Step 1: Clone Repository

```bash
git clone https://github.com/your-username/Rent_Vechical_in_Uttarakhand.git
```

### Step 2: Move Project

Copy the project folder into:

```text
C:\wamp64\www\
```

### Step 3: Start WAMP Server

Start:

* Apache
* MySQL

### Step 4: Import Database

1. Open phpMyAdmin
2. Create a database
3. Import `database.sql`

### Step 5: Configure Database

Update database credentials inside:

```php
config.php
```

### Step 6: Run Project

Open:

```text
http://localhost/Rent_Vechical_in_Uttarakhand
```
